# Mac Stats Block Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A «Mac» block in the AI Status Bar menu that names the bottleneck, lists the top 3 consumers grouped by ownership tree, and lets the user quit them or agent leftovers.

**Architecture:** Pure model (`SystemModel.swift`: grouping, leftovers, verdict) fed by a thin kernel reader (`SystemSampler.swift`), a guarded killer (`ProcessKiller.swift`), and SwiftUI rows + menu builder (`SystemMenu.swift`) wired into `main.swift`. The spike file `SystemSpike.swift` is deleted.

**Tech Stack:** Swift 5.9, AppKit/SwiftUI, Darwin `libproc`, Mach `host_statistics64`, `sysctl`; XCTest.

**Spec:** `docs/superpowers/specs/2026-11-16-mac-stats-design.md`

## Global Constraints

- macOS 14+, no new dependencies, no network, no shelling out.
- Colours: alarm chips `asbWarnFill` #B85A00 / `asbDangerFill` #D92D20 with white text; text never below 4.5:1.
- Thresholds: CPU ≥70 warn, ≥90 critical; memory alarm only from `kern.memorystatus_vm_pressure_level` (1/2/4).
- Rows: `MenuRowFactory.rowWidth` 260, `rowHeight` 25; fixed block height = summary + 3 consumer rows.
- Only current-uid processes are ever signalled; never pid 0/1, own pid, own ancestors.
- Leftover ≥60 s old; agent CLIs: `claude`→«Claude Code», `codex`→«Codex», `gemini`→«Gemini CLI», `opencode`→«OpenCode», `aider`→«Aider», `cursor-agent`→«Cursor Agent», `amp`→«Amp».

## Review Focus

- A process whose parent exits between `proc_listallpids` and `proc_pidinfo` (racy snapshot) → skipped, no crash. Test: `testGroupingToleratesMissingParent`.
- Parent-pid cycle or self-parent in data → no infinite loop. Test: `testGroupingSurvivesCycle`.
- Fewer than 3 consumers (fresh boot / mock) → block still has 3 rows' worth or pads safely; never index out of range. Test: `testTopConsumersPadsWhenFew` (returns ≤3, UI hides empty rows by `isHidden`).
- Quit All on an agent group that contains this app's own ancestor (app launched from a Claude session) → those pids filtered out. Test: `testKillTargetsExcludeSelfAndAncestors`.
- launchd daemons and `.app` helpers with `ppid 1` never classed as leftovers. Test: `testLeftoverRejectsGroupLeaderAndAppBundle`.

### Task 1: Pure model — grouping, leftovers, verdict

**Files:**
- Create: `Sources/AIStatusBar/SystemModel.swift`
- Test: `Tests/AIStatusBarTests/SystemModelTests.swift`

**Interfaces:**
- Produces:
  - `struct ProcSample: Equatable { pid, ppid, pgid: Int32; uid: uid_t; name: String; path: String; footprint: UInt64; cpuTime: Double /*s*/; startedAt: Date; args: [String] }`
  - `enum Level: Int, Comparable { case normal, warn, critical }`
  - `struct Consumer: Equatable { key: String; title: String; kind: ConsumerKind; rootPids: [Int32]; allPids: [Int32]; footprint: UInt64; cpuPercent: Double; helpers: Int }` with `enum ConsumerKind: Equatable { case agent, app(bundlePath: String), process, leftovers }`
  - `struct Leftover: Equatable { pid: Int32; label: String; tool: String; age: TimeInterval; footprint: UInt64; treePids: [Int32] }`
  - `struct SystemSnapshot { cpuPercent: Double; memUsed, memTotal, swapUsed: UInt64; pressure: Level; consumers: [Consumer]; leftovers: [Leftover]; takenAt: Date }`
  - `enum SystemModel { static func group(_ procs: [ProcSample], cpuPercentByPid: [Int32: Double], ownUid: uid_t) -> [Consumer]; static func leftovers(_ procs: [ProcSample], ownUid: uid_t, now: Date) -> [Leftover]; static func top(_ s: SystemSnapshot, verdict: Verdict) -> [Consumer] /* ≤3, leftovers merged as one .leftovers consumer ranked by summed footprint */ }`
  - `struct Verdict: Equatable { text: String; level: Level; byCPU: Bool; init(_ s: SystemSnapshot) }`
  - `enum ByteText { static func gb(_ bytes: UInt64) -> String /* "7.4 GB", <1 GB → "9 MB" */ }`
